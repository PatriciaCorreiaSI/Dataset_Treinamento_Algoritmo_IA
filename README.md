Criação de Dataset a partir de imagens de gatos e cachorros extraídas do site kaggle para teste de treinamento de algoritmo de inteligência artificial

#
Este projeto faz parte de uma trilha de aulas sobre Fundamentos e Técnicas de Machine Learning oferecidas pela DIO. A proposta do projeto é criar uma base de dados (dataset) para o treinamento de um algoritmo baseado em Redes Neurais Artificiais. Para essa tarefa foi criada duas classes de objetos com no mínimo 100 imagens para cada uma delas (gatos e cachorros). Esse dataset servirá como base para os projetos desenvolvidos ao longo de toda a trilha, em diferentes projetos.
